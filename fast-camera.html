About this reader
  • A verified read appears instantly in the result card. The live camera keeps reading; a changed or unverified frame clears it.
  • The camera preview stays live while a background worker searches. A lightweight visual tracker moves the overlay between verified reads. Tracking is not a new decode and may drift; the overlay disappears when tracking is uncertain.
  • Accuracy comes first. Every displayed value passed ECC and CRC. Each frame search is limited to 980 ms; a missed frame returns no new value. Every frame uses a fresh bounded decode. This camera update has no physical-phone speed or accuracy guarantee. Desktop synthetic tests are not phone-photo validation.
  • Original pixels are tried before enhancement. The automatic fallback uses local exposure and contrast normalization plus a fitted nonlinear surface. It does not use sharpening or a phone enhancement pipeline. Existing reader glare erasures can handle some damage
  • Only http/https payloads become links. Nothing opens automatically. Check the full address before tapping. CRC checks integrity, not the sender's identity.
  • Camera needs HTTPS and permission. Close other camera apps if it is unavailable. No video, photo or decoded value is uploaded or saved by this page. Backgrounding the page stops the camera.
  • Version 0.3.1. Designed for moderate capture conditions; extreme images may fail. Tested with synthetic camera input and phone-browser emulation, not a physical phone's autofocus, glare or motion.
