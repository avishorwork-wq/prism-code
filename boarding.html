Issued

What is inside the code
  • A standard IATA boarding pass text line (the same fields a PDF417 or QR boarding pass carries): passenger, booking ref, route, flight, day, seat, sequence.
  • One extra line with gate, terminal, boarding and departure times, full date, refresh time and the pass's own public key.
  • The airline signature and public key (129 bytes).
  • On the passenger device: a time stamp signed with the pass key, renewed at the refresh time you choose. The gate rejects a code that is older than the refresh time plus 25 s.

Real world notes
  • Gate scanners and kiosks today read IATA BCBP in PDF417, QR and Aztec. Prism runs in a phone-based gate app, so an airline adds it with no new hardware.
  • Here the airline signs the pass and the gate checks that signature without a network. That is stronger than plain BCBP, which has an optional security field that most airlines leave empty.
  • This demo has no booking system, check-in, seat inventory, no-fly checks, revocation or live gate changes. Those are the real work.
