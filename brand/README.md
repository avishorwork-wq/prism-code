# Prism Code brand kit

Mark: seven hex cells in the code's own palette, one cell left out. The gap is the rotation notch, the same cue the code uses.

Palette: red #D7263D, orange #F77F00, yellow #F5C518, green #2DB35A, cyan #00B8D9, blue #2E5BFF, magenta #B5179E. Ink #1B1B1B, muted #585254, ground #F4EFEC.
Wordmark: "Prism" bold sans, "CODE" tracked small caps in muted grey. Text is converted to outlines, no font needed.

Use: keep clear space of one cell around the mark. On dark grounds use the on-dark files (center cell turns white). One-color uses: prism-mark-black.svg, prism-mark-white.svg. Do not recolor cells, rotate, or fill the gap.
Files: SVG sources plus PNG icons 16 to 1024, maskable 512, social card 1200x630, favicon.ico.
Install: manifest.webmanifest, prism-sw.js and install.html go in the repo root next to index.html.
Add to each page head: <link rel="manifest" href="manifest.webmanifest"><link rel="icon" href="brand/icon-32.png"><link rel="apple-touch-icon" href="brand/icon-180.png">
