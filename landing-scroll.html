Prism Secure

Lock it. Password-protect a code with AES-256-GCM. The password goes through Argon2id (128 MiB, 3 passes) to make guessing expensive. Anyone who photographs a locked code sees random data, and any change to it is detected.

Sign it. Add an ECDSA P-256 signature so people can tell the code is unchanged and made by one key.

QR codes can be encrypted too, but only if each app adds its own scheme: a QR has no built-in lock. Prism Secure is not independently audited. A weak password can be guessed offline from a photo. A signature proves who made the code only if the reader already trusts that key. No password recovery.

How it works

  1. Type text or a link in Create, or lock it in Prism Secure. Download the PNG.
  2. Print it or show it on a screen. Keep the white margin.
  3. Open Scan, point the camera. The value appears under the code.
