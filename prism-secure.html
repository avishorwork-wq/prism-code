What this protects, and what it does not
  • Protects: anyone who scans or photographs a locked code sees only random data. Any change to the code is detected.
  • Lock: AES-256-GCM. The password goes through Argon2id (128 MiB, 3 passes), which makes guessing expensive. Every code has its own random salt and nonce.
  • Sign: ECDSA P-256. Shows the code is unchanged and made by one key. It proves who only if you already trust that key's fingerprint.
  • Does not protect: a weak password, a phone or computer with malware, someone watching you type, the fact that a code exists or roughly how long it is, or a password shared with the wrong person.
  • No recovery for a lost password or key. Not independently audited: it uses the browser's built-in crypto plus the MIT-licensed hash-wasm Argon2id.
